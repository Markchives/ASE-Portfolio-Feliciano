# Course Introduction

## Course Details
- **Course Code:** CPELX230-330
- **Course Title:** CPE Elective 2 and 3 (Agentic Software Engineering)
- **Program:** Computer Engineering, National University
- **Term:** Term 2, AY 2026–2027
- **Pre-requisite:** CPELX230 CPE Elective 2

## About the Course
This course teaches Agentic Software Engineering, which means building software with the help of AI agents. Students learn how AI can support every stage of making software: gathering requirements, designing, coding, testing, writing documentation, deploying, and maintaining. The course focuses on working together with AI, writing good prompts, using AI responsibly, and checking that AI-generated work is correct and safe.

## Course Outcomes
By the end of the course, students should be able to:
1. Use modern software development life cycle (SDLC) processes, tools, and technologies.
2. Write, review, and evaluate software requirements.
3. Design and build software that meets those requirements.
4. Use modern testing and quality techniques to make sure the software works well.

## Course Requirements
- Individual exercises, quizzes, and exams
- Hands-on activities in Python, GitHub, AI, testing, and deployment
- A team project that must include:
  - an AI agent
  - human oversight
  - security controls
  - automated testing
  - CI/CD and deployment
  - monitoring
  - a responsible AI evaluation
