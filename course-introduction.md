# Course Introduction

Course Code: CPELX230-330
Course Title: CPE Elective 2 and 3 (Agentic Software Engineering)
Program: Computer Engineering, National University
Term: Term 2, AY 2026–2027
Pre-requisite: CPELX230 CPE Elective 2

## About the Course
This course introduces Agentic Software Engineering, a way of building software where AI agents are part of the software development life cycle. Students learn how AI systems can help with requirements, design, coding, testing, documentation, deployment, and maintenance. The course stresses human-AI collaboration, prompt engineering, responsible AI, and checking the quality of AI-generated work.

## Course Outcomes
1. Apply modern SDLC processes, tools, and technologies.
2. Construct, examine, and evaluate requirements.
3. Design and develop software based on the requirements.
4. Apply modern software quality and testing techniques.

## Course Requirements
Individual exercises, quizzes, and exams; Python, GitHub, AI, testing, and deployment activities; and a team project that includes an AI agent, human oversight, security controls, automated testing, CI/CD, deployment, monitoring, and a responsible AI evaluation.
